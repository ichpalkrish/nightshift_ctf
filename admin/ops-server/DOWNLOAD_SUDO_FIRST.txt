BEFORE BUILDING: the vulnerable sudo .deb is not committed to the repo
(it's a 926KB binary). Download it into THIS directory first:

  curl -L -o sudo_vuln.deb \
    "http://archive.ubuntu.com/ubuntu/pool/main/s/sudo/sudo_1.9.15p5-3ubuntu5_amd64.deb"

Verify it's the real package (should say "Debian binary package"):
  file sudo_vuln.deb

Then build from the admin/ directory:
  docker compose up --build

NOTE: this is the amd64 build. On Apple Silicon, docker-compose.yml already
pins `platform: linux/amd64` so Docker Desktop emulates it via QEMU.
